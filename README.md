# Номидоо ♡

Утсанд зориулж зохиосон, координатын хаалгатай романтик дурсамжийн цомог. Нэмэлт npm dependency шаардлагагүй. Node.js 20.11+ ашиглана.

## Ажиллуулах

```sh
cd /workspace/hoorhonNomi
npm run dev
```

Сервер 3000 порт дээр ажиллана. Өөр портод `PORT=3001 npm run dev`.
`npm run check` нь JavaScript syntax шалгана.

Нэвтрэх координат: **N 40.8575 · W 81.5937**. Таслалаар аравтын бутархай бичихийг мөн зөвшөөрнө.

## Зургууд

Одоогоор оруулсан 15 зураг бүгд цомогт холбогдсон. Эх файлууд `photos/`, вебд зориулж жижигрүүлсэн WebP хувилбарууд `photos/web/` дотор байна. Нүүрний зураг нь `3658.jpg`-ийн WebP хувилбар. Эх зургуудаа өөрчлөөгүй; веб хувилбарууд нь EXIF/GPS metadata агуулахгүй.

Зураг болон тайлбарыг `app.js` файлын эхний `memories` жагсаалтаас солино. `image` нь зургийн зам, `title` нь гарчиг, `caption` нь тайлбар, `location` нь дэлгэрэнгүй цонхны тэмдэглэгээ. Шинэ зураг нэмэхдээ энэ жагсаалтад шинэ бичлэг нэмнэ.  Цомог шүүлтүүргүй; доор нь тайлбаргүйгээр зургуудыг өөрийн харьцаагаар бүтнээр харуулна.

Нүүрний зургийг өөрчлөх бол `app.js`-ийн төгсгөл дэх `heroPhoto.src` замыг солино. Зураг дээр дарахад бүтнээр нь харагдана. Шинэ зургаа 1600px хүртэл жижигрүүлсэн WebP форматаар экспортлоод `photos/web/` хавтаст байрлуулахыг зөвлөе. Browser-оос upload хийж хадгалах систем биш.

Бүтэн захиа `app.js` доторх `letter` жагсаалтад байна. Google Fonts хүрэхгүй бол системийн фонтоор ажиллана.

## Нийтлэх

`index.html`, `style.css`, `romance.css`, `handwriting.css`, `app.js`, `photo-captions.js`, `photos/`, `fonts/` файлуудыг дурын статик хостингт байрлуулж болно. Build алхам шаардлагагүй. Node сервер ашиглавал `npm start`.

Координатын хаалга нь бэлгэдлийн UI бөгөөд нууцлалын хамгаалалт биш. Захиа болон зургууд browser-оос шууд уншигдана. Хувийн хэрэглээнд нийтлэхдээ хостингийн жинхэнэ нэвтрэлт/хандалтын хамгаалалтыг ашиглана. «Тэгье» товч нь зөвхөн тухайн хуудсанд мэндчилгээ харуулдаг; хариуг хадгалж, илгээхгүй.

Координатаар нэвтэрсний дараа тухайн browser дээр localStorage-д 7 хоногийн хугацаа хадгална. Refresh эсвэл дахин нээхэд энэ хугацаанд код асуухгүй. Browser-ийн мэдээллээ цэвэрлэх, өөр browser ашиглах эсвэл буцаж түгжих товч дарахад дахин код оруулна. Storage хаалттай бол нэвтрэлт ажиллах ч санах боломжгүй.

## Өөрийн зургийн тайлбар бичих

`photo-captions.js` файлыг нээгээд файлын нэрийн тоонд харгалзах хоосон хашилтын дотор бичнэ. Жишээ:

```js
"238": "Jellystone — бидний анхны алхам ♡",
"1589": "Чамтай явах зам хамгийн гоё.",
```

Хадгалаад browser-оо refresh хийнэ. Тайлбар нь зургийн доор болон дэлгэж үзэхэд харагдана. Хоосон утгатай зураг доор бичвэр гарахгүй. Давхар хашилт оруулахдаа `\"` гэж бичих эсвэл “ийм” хашилт ашиглана. Бусад мөрийн таслалыг хэвээр үлдээнэ. Өөрийн компьютерт зассан тайлбараа нийтлэхийн тулд энэ файлаа мөн commit/push хийнэ.

Нэвтрэх анимейшнийг дахин үзэхдээ баруун дээд булангийн «Бидний орон зай →» (утсан дээр ♡ →) товчоор гарч, кодоо дахин оруулна. Энэ нь хадгалсан 7 хоногийн нэвтрэлтийг мөн цэвэрлэнэ. Эсвэл DevTools Console дээр `localStorage.removeItem('nomi-entry-until'); location.reload();` ажиллуулна. Token, cookie бүгдийг устгах шаардлагагүй. Хадгалсан нэвтрэлтээр дахин ороход мэндчилгээ давтагдахгүй. Хөдөлгөөн багасгах тохиргоотой бол анимейшн тоглохгүй.

Дэлгэсэн зураг дээр баруун/зүүн swipe, mouse drag, сумтай товч эсвэл keyboard-ийн ← → ашиглана. Эхний/сүүлийн зураг хоорондоо үргэлжилнэ. Нүүрний зураг одоо `photos/web/1589.webp`.

## Дараалал болон хуруугаар зураг шилжүүлэх

`photo-captions.js` файлын доод хэсгийн `window.PHOTO_ORDER` жагсаалтын мөрүүдийг дээш/доош зөөнө. Жишээ:

```js
window.PHOTO_ORDER = [
  "1589",
  "238",
  "3658",
  // бусад зургийн нэрийг үргэлжлүүлнэ
];
```

Жагсаалтад бичээгүй зураг устахгүй, сүүлд нь харагдана. Энэ дараалал цомог болон дэлгэсэн зургийн swipe-д адил үйлчилнэ. Зургууд PHOTO_ORDER дарааллаар зүүнээс баруун тийш, дараа нь дараагийн мөр рүү орно. Утас, таблет дээр 2 багана, 900px-ээс өргөн дэлгэц дээр 3 баганатай. Зураг бүр өөрийн харьцаагаар бүтнээрээ харагдана. Нүүрний зураг тусдаа `heroPhoto.src` утгаар сонгогдоно.

Дэлгэсэн зураг дээр хуруугаараа зүүн тийш шудрахад дараах, баруун тийш шудрахад өмнөх зураг гарна. Сумтай товчуудыг арилгасан; компьютер дээр mouse drag эсвэл keyboard-ийн ← → хэрэглэнэ. Босоо гүйлгэх, хоёр хуруугаар томруулах боломжийг хадгалсан.

Захианы бүх текст, гарын үсэг 16px. `handwriting.css` дотор монгол кирилл ө/ү дэмждэг Caveat фонтыг шууд багтаасан тул font URL ачаалах, хуучин сервер TTF буцаахгүй байх асуудлаас хамаарахгүй. Шинэ CSS/JS холбоосуудад хувилбарын дугаар нэмсэн. Local серверээ шинэчилсний дараа хуучин загвар харагдвал Ctrl+Shift+R хийнэ.

## Vercel deployment

1. Vercel-д GitHub account-аа холбоод **Add New → Project** дотроос `Aldaraa05/hoorhonNomi` repo-г импортлоно.
2. Root Directory-г repo-ийн үндсэн хавтас, Framework Preset-г **Other** байлгана. `vercel.json` нь Build Command: `npm run build`, Output Directory: `dist` гэж тохируулна. Environment variable шаардлагагүй.
3. **Deploy** дарна. Амжилттай болсон deployment-ийн Visit холбоос нь нийтлэгдсэн сайтын URL болно.
4. Git integration болон Production Branch `main` байвал дараагийн push бүр шинэ production deployment үүсгэнэ. Deploy амжилттай болсны дараа ижил URL дээр шинэ хувилбар гарна. Photos болон `photo-captions.js` өөрчлөлтүүдэд мөн адил.

`npm run build` нь `dist/` үүсгэнэ. Зөвхөн сайтын файл, вебд зориулсан жижиг зургууд, фонтыг хуулна; эх хэмжээтэй зургууд, Git metadata, development server-ийг нийтлэхгүй. Тусдаа Node backend шаардлагагүй. `dist/`-ийг гараар засахгүй, эх файлаа засаад build хийнэ.

## Нууц зурвас, дуу, утсандаа хадгалах

- Нүүрний зургийн доорх зүрх, «100 өдөр»-ийн зүрх, төгсгөлийн хязгааргүйн дундах зүрхэн дээр дарахад жижиг зурвас нээгдэнэ. Үгсийг `keepsakes.js`-ийн `notes` жагсаалтаас өөрчилнө.
- Пянзны товчоор Lana Del Rey — Video Games дууны YouTube тоглуулагчийг нээнэ. Товч дарахаас өмнө YouTube iframe ачаалахгүй. Хаах эсвэл координатын хаалга руу гарахад iframe арилж, тоглуулах нь зогсоно. Browser автоматаар эхлүүлэхийг хоригловол тоглуулагчийн Play дээр дарна. Embed боломжгүй, тухайн бүс/сүлжээнд хаалттай бол YouTube дээр нээх холбоосыг ашиглана. Аудио файлыг repo-д хадгалаагүй.
- «Утсандаа хадгалах» товч Android/Chrome-д суулгах боломжтой үед системийн Install prompt гаргана. iPhone дээр Safari → Share → Add to Home Screen → Add. Vercel-ийн HTTPS холбоосыг үндсэн browser-оор нээнэ. Суусан үед тусдаа цонхтой, a & n зүрхэн icon-той байна. Жинхэнэ утсан дээрх системийн install үйлдлийг хэрэглэгч хийнэ.
- `manifest.webmanifest`, `icons/`, `sw.js` нь PWA файлууд. Service worker өөрийн сайтын файлд network-first ашиглаж, сүлжээгүй үед өмнө хадгалсан хуудсыг харуулна. Үзсэн зураг cache-д үлдэнэ; хараахан ачаалаагүй зураг болон YouTube дуу offline ажиллахгүй. Нэвтрэх 7 хоногийн хугацаа хэвээрээ.
- Дараа нь өөрчлөхөд `main` руу push хийгээд Vercel build амжилттай дууссаны дараа хуудсаа дахин нээж/refresh хийж шинэчлэгдсэн хувилбарыг авна. Эх файлуудаа засна, `dist/`-ийг гараар өөрчлөхгүй.
