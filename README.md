# Номидоо ♡

Утсанд зориулж зохиосон, координатын хаалгатай романтик дурсамжийн цомог. Нэмэлт npm dependency шаардлагагүй. Node.js 20.11+ ашиглана.

## Ажиллуулах

```sh
cd /workspace/hoorhonNomi
npm run dev
```

Сервер 3000 порт дээр ажиллана. Өөр портод `PORT=3001 npm run dev`.
`npm run check` нь JavaScript syntax шалгана.

Нэвтрэх координат: **N 40.8575 · W 81.5937**. Таслалаар аравтын бутархай бичихийг мөн зөвшөөрнө.

## Зургууд

Одоогоор оруулсан 15 зураг бүгд цомогт холбогдсон. Эх файлууд `photos/`, вебд зориулж жижигрүүлсэн WebP хувилбарууд `photos/web/` дотор байна. Нүүрний зураг нь `3658.jpg`-ийн WebP хувилбар. Эх зургуудаа өөрчлөөгүй; веб хувилбарууд нь EXIF/GPS metadata агуулахгүй.

Зураг болон тайлбарыг `app.js` файлын эхний `memories` жагсаалтаас солино. `image` нь зургийн зам, `title` нь гарчиг, `caption` нь тайлбар, `location` нь шүүлтүүрийн ангилал. Шинэ зураг нэмэхдээ энэ жагсаалтад шинэ бичлэг нэмнэ. Нийт тоо автоматаар шинэчлэгдэнэ. Одоо байгаа ангиллаас сонгох эсвэл `index.html`-ийн шүүлтүүрт шинэ ангиллаа мөн нэмнэ.

Нүүрний зургийг өөрчлөх бол `app.js`-ийн төгсгөл дэх `heroPhoto.src` замыг солино. Зураг дээр дарахад бүтнээр нь харагдана. Шинэ зургаа 1600px хүртэл жижигрүүлсэн WebP форматаар экспортлоод `photos/web/` хавтаст байрлуулахыг зөвлөе. Browser-оос upload хийж хадгалах систем биш.

Бүтэн захиа `app.js` доторх `letter` жагсаалтад байна. Google Fonts хүрэхгүй бол системийн фонтоор ажиллана.

## Нийтлэх

`index.html`, `style.css`, `romance.css`, `app.js`, `photos/` файлуудыг дурын статик хостингт байрлуулж болно. Build алхам шаардлагагүй. Node сервер ашиглавал `npm start`.

Координатын хаалга нь бэлгэдлийн UI бөгөөд нууцлалын хамгаалалт биш. Захиа болон зургууд browser-оос шууд уншигдана. Хувийн хэрэглээнд нийтлэхдээ хостингийн жинхэнэ нэвтрэлт/хандалтын хамгаалалтыг ашиглана. «Тэгье» товч нь зөвхөн тухайн хуудсанд мэндчилгээ харуулдаг; хариуг хадгалж, илгээхгүй.
