# Номидоо ♡

Утсанд зориулж зохиосон, координатын хаалгатай романтик дурсамжийн цомог. Нэмэлт npm dependency шаардлагагүй. Node.js 20.11+ ашиглана.

## Ажиллуулах

```sh
cd /workspace/hoorhonNomi
npm run dev
```

Сервер 3000 порт дээр ажиллана. Өөр портод `PORT=3001 npm run dev`.
`npm run check` нь JavaScript syntax шалгана.

Нэвтрэх координат: **N 40.8575 · W 81.5937**. Таслалаар аравтын бутархай бичихийг мөн зөвшөөрнө.

## Өөрсдийн зургуудыг нэмэх

Код өөрчлөхгүйгээр JPG зургуудаа доорх нэрээр `photos/` хавтаст хуулж тавина. Дараа нь хуудсаа refresh хийнэ.

| Файлын нэр | Байрлал |
| --- | --- |
| `cover.jpg` | Нүүрний том зураг |
| `01.jpg` | Jellystone |
| `02.jpg` | New York · SUMMIT |
| `03.jpg` | New York · Brooklyn Bridge |
| `04.jpg` | Cleveland |
| `05.jpg` | Солонгос |
| `06.jpg` | Монгол |

Зургийг жинхэнэ JPG форматаар экспортлоорой; зөвхөн өргөтгөлийг солихгүй. Зураг байхгүй бол түр дүрслэл үлдэнэ. Вебд зориулж хэмжээг багасгаж, GPS/EXIF мэдээллээ арилгахыг зөвлөе. Бусад формат, нэмэлт зураг оруулах бол `app.js`-ийн `memories` жагсаалтад image зам болон шинэ бичлэг нэмж болно. Тайлбарыг мөн тэнд өөрчилнө. Энэ нь серверт байрлуулах файл нэмэх арга; browser-оос upload хийж хадгалах систем биш.

Бүтэн захиа `app.js` доторх `letter` жагсаалтад байна. Google Fonts хүрэхгүй бол системийн фонтоор ажиллана.

## Нийтлэх

`index.html`, `style.css`, `romance.css`, `app.js`, `photos/` файлуудыг дурын статик хостингт байрлуулж болно. Build алхам шаардлагагүй. Node сервер ашиглавал `npm start`.

Координатын хаалга нь бэлгэдлийн UI бөгөөд нууцлалын хамгаалалт биш. Захиа болон зургууд browser-оос шууд уншигдана. Хувийн хэрэглээнд нийтлэхдээ хостингийн жинхэнэ нэвтрэлт/хандалтын хамгаалалтыг ашиглана. «Тэгье» товч нь зөвхөн тухайн хуудсанд мэндчилгээ харуулдаг; хариуг хадгалж, илгээхгүй.
